# Known regrtest failures of the PY_TARGET_XP build, on top of

# the XP build lacks:
#
#   python.exe -m test -j2 -u all,-gui,-network -x test_wmi test_venv \
#       --ignorefile Platforms/w64devkit/tests/expected_failures.txt \
#       --ignorefile Platforms/w64devkit/tests/xp/expected_failures.txt
#
# test_wmi: no _wmi (it needs Vista's WMI and propsys).
# test_venv: no venv launchers (PathCch, Windows 8).

# - os.stat() of a path gets the 64-bit volume serial number through
#   Windows 11's GetFileInformationByName, os.fstat() the 32-bit one through
#   the fallbacks: their st_dev differ.  (On XP both are 32-bit.)
